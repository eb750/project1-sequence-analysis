# project1-sequence-analysis
This program analyses and compares samples that have undergone next generation sequencing with a reference sequence in order to identify substitution mismatches. This allows an in-depth analysis of differences in mismatches between control and treated samples. 

To run the program, import the relevant files for the sequencing reads and reference sequence. Starting with the setup code, run each code cell in order using the provided functions and analysis steps, with each function being reused and built on in subsequent steps to develop the program further.

The program is expecting two input files, one being a reference sequence, and the other consisting of reads, containing sequencing data from various biological samples. Output will display summary information about the read sequences, beginning with whether results are valid and mismatch information. Additionally, reads will be analysed to find mismatch frequencies percentages, along with a comparison of these between control and treatment groups. 

Functions were divided according to individual tasks in order to avoid code repetition, creating a structured program, improving readability and testability. In particular, helper functions were used in summarise_samples() to calculate summary information for individual samples, as well as to investigate the frequency of substitution mismatches. Additionally, dictionaries were used to organise and store mismatches by their position, allowing counts to be accessed by sample and position. This made it easier to retrieve and rank positions during further statistical analysis. Furthermore, accuracy of calculations was secured by identifying and excluding invalid reads, preventing these sequences from affecting results in subsequent analysis. This summary information was reused in compare_positions() to minimise code repetition and avoid recalculating previously obtained values. Conditional statements were used to handle samples containing no valid reads and edge cases, preventing division-by-zero errors.

Code was tested using assert statements on manually created test datasets with known mismatch counts, which were modified for further testing to ensure the code would work on any dataset. Valid and invalid reads were tested to ensure that sequence lengths and nucleotide bases were identified correctly. Sequences containing known mutations were also used to verify mutation identification and position. Edge cases, including empty lists and sequences with no mutations were also tested to confirm that invalid inputs were handled correctly.
